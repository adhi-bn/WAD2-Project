# Lechaton Typers

Custom mechanical-keyboard builder: users assemble a keyboard from compatible parts within a budget.

## Language

**Build**:
A user-assembled keyboard made by choosing one Part in each slot.
_Avoid_: Configuration, custom keyboard

**Part**:
One selectable component for a Build, in exactly one of five slots: layout, frame, weight, switches, keycaps.
_Avoid_: Component, item

**Barebones kit/**:
The base unit of a Build that switches and keycaps attach to.
_Avoid_: Base, kit

**Compatibility**:
Whether the chosen switches, keycaps, and barebones for a Build fit together. PCB and foam are out of scope.
_Avoid_: Validity, match

**Budget**:
The live price total of a Build compared against the user's limit.
_Avoid_: Price, cost
